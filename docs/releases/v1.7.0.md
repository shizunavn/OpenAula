# OpenAula v1.7.0

AULA WIN 68 HE MAX & HERO 68 XS Hardware Imagery, Switch Visual Assets & 8K Receiver Support.

## Hardware Visual Imagery & Keyboard Assets

- **AULA WIN 68 HE MAX Thumbnail**:
  - Added authentic hardware image asset (`src/assets/win68HeMax.png`).
  - Updated `WIN68_HE_MAX_BOARD` and `DeviceConnectionPanel` to render dedicated WIN 68 HE MAX thumbnail instead of generic HERO68 placeholder.
- **AULA HERO 68 XS Crystal Edition Thumbnail**:
  - Added authentic crystal-edition hardware asset (`src/assets/hero68xs.png`).
  - Automatically switches thumbnail in `DeviceConnectionPanel` when connected keyboard is recognized as HERO 68 XS.

## Authentic Switch Visual Assets

- Added high-resolution front and top photography for 5 magnetic switch varieties:
  - Lingyun Magnetic (`switch-59`, `lingyun-front.png`, `lingyun-top.png`).
  - Snow God / Xue Shen (`switch-60`, `snowgod-front.webp`, `snowgod-top.png`).
  - Nick Magnetic (`switch-61`, `nick-front.png`, `nick-top.png`).
  - Ice Jade (`switch-62`, `icejade-front.png`, `icejade-top.png`).
  - Ash Wood (`switch-37`, `ashwood-front.png`, `ashwood-top.png`).
- Registered in `SWITCH_IMAGES` in `src/app/switchAssets.ts` for per-key switch previews.

## HERO 68 XS 8K Receiver & 5 µm Precision Scale

- Added 8K wireless receiver (`PID 0x106C`) to background service HID bridge filter (`service/native/hid_bridge.cpp`).
- Added dynamic distance scaling (`0.005 mm` / `5 µm`) for HERO 68 XS queries via CMD `0x82` zone 6/8.
