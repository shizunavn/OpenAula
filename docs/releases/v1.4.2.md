# OpenAula v1.4.2

WIN 68 HE MAX Rhythm Sync Audio Noise Floor Gating & Native Stream Priority.

## Audio Noise Floor Gating & Silence Dark State

- Clean dark state on silence:
  - Added background noise threshold gating on both FFT bins (`raw > 4 ? (raw - 4) / 251 : 0`) and time-domain waveform RMS (`rms > 0.005 ? rms : 0`).
  - When the audio level drops below 0.008, all 68 key LEDs are set to `#000000` (off) and side LEDs transition to idle `#181c20`, eliminating annoying flicker and unwanted synth animations during silent passages or pauses in playback.
- Enforced live audio stream integrity:
  - Removed illustrative synth fallback in live mode (`allowSynthFallback = false`), ensuring real microphones and system audio streams never display artificial rhythm pulses when no sound is present.
  - Automatically migrated obsolete `web-synth` audio endpoint settings in persisted user profiles to `default`.

## Stream Priority & Concurrency Clean-Up

- Single-master USB streaming:
  - Cleaned up dual-engine contention: when the native Windows service is actively running Rhythm Sync, stray browser Web Audio loops are immediately halted to prevent conflicting packets over WebHID.
  - Re-anchored SSE `/frames` event streaming in `RhythmPreview`, preventing preview jitter between simulated and live service frames.
  - Corrected `sideMode` propagation for WIN 68 HE MAX (`sideMode: 500`) to guarantee onboard side LED lighting is preserved.

## Quality Assurance & Verification

- Added regression tests in `tests/rhythm.test.mjs` confirming 100% dark state across all 5 rhythm modes during audio silence.
- Added live preview stability assertions in `tests/rhythm-xsyd-service.test.mjs`.
