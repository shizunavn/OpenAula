# OpenAula v1.3.2.1

RGB color controls redesign and 1.0 mm dead zone slider limit.

## 1.0 mm Dead Zone limit

The top and bottom dead zone sliders in Rapid Trigger and Quick Settings now extend up to 1.0 mm (previously capped at 0.5 mm). The underlying firmware protocol already handles values in micrometres, allowing deeper dead zones without protocol modifications.

## Redesigned RGB Color Controls

- **Unified Custom Color Picker**: A modern color box combining a native color picker with an editable uppercase HEX input.
- **8-Slot Swatch Grid**: Directly toggle Multicolor or select from the 7 hardware color slots with clear visual dot swatches and active state highlights.
- **Cleaned-up Mode Views**: Onboard effects and Custom Effect base/layers cleanly separate Single Color from Multicolor/Palette strips, hiding redundant slot strips when Single Color is selected.
- **Per-Key Paint Tools**: Replaced text buttons with compact circular color chips and improved layout.
- **Dedicated Reverse Row**: Effect direction toggle is rendered as a full-width toggle row with distinct iconography.

## Validation

676 JavaScript tests pass, the web application builds with Vite, and both TypeScript projects (UI and service) typecheck cleanly.
