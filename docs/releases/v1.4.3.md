# OpenAula v1.4.3

WIN 68 HE MAX DKS & 4-Mode SOCD Support.

## DKS (Dynamic Keystroke) Implementation for WIN 68 HE MAX

- Full DKS support on XSYD architecture via opcode `0x26`, payload length 16 (`0x10`):
  - Verified against firmware disassembly (`VA 0x0B718..0x0B9FE`) and USB capture `dks_keyW_down1.4-3.4_up3.4-1.4_A-hold1_B-hold2_C-hold3_D-end.pcapng`.
  - Configures 4 distinct key actions (`action0` through `action3`) and phase masks (`mask0` through `mask3`) mapped to firmware ROM table `VA 0x1D524`.
  - Configures DKS actuation depth clamped to maximum switch travel.
  - Enabled DKS UI card on WIN 68 HE MAX in `AdvancedKeysPage.tsx`.

## 4-Mode SOCD Resolution for WIN 68 HE MAX

- SOCD opcode `0x2C` (LEN 11, handler `VA 0x0BD20..0x0BF8E`):
  - Supports all 4 firmware resolution modes:
    1. `0x00`: Last input priority
    2. `0x01`: First key priority
    3. `0x02`: Second key priority
    4. `0x03`: Neutral

## Repository Standardization

- Added `.gitattributes` to standardize LF line endings and prevent CRLF churn across operating systems.
