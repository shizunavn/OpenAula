# OpenAula v1.5.1

WIN 68 HE MAX DKS 7-Node Visual Track & Official Keycap Palette.

## DKS 7-Node Visual Track Editor

- Official AULA-styled 7-node visual track interface:
  - Modeled after official AULA software:
    - Phase 0 → Phase 1 (`0x03`): nodes 0 & 1 lit, segment 0 active.
    - Phase 1 → Phase 2 (`0x1C`): nodes 2 & 3 lit, segment 2 active.
    - Phase 2 → Phase 3 (`0x60`): nodes 4 & 5 lit, segment 4 active.
    - Phase 3 End (`0xC0`): nodes 5 & 6 lit, segment 5 active.
  - Interactive keycap palette with 6 official categories:
    - LETTER, NUMBER KEY, SYMBOLIC KEY, BASIC KEY, FUNCTION KEY, KEYBOARD CONTROL.

## Hardware-Accurate Defaults & Modifier Transcoding

- Configures DKS on WIN 68 HE MAX with verified 4-stage stairstep actions `[4, 5, 6, 7]` matching `dks_keyW_down1.4-3.4_up3.4-1.4_A-hold1_B-hold2_C-hold3_D-end.pcapng`.
- Converts 32-bit modifier keycodes (such as Left Shift `0x00020000`) to native XSYD action bytes (`0xE1`), ensuring presets like "DKS Running" work out-of-the-box on WIN 68 HE MAX.

## Quality Assurance & Verification

- Added integration tests in `tests/xsyd-win68-integration.test.mjs` verifying node mapping, segment lighting, palette categorization, and modifier byte conversion.
