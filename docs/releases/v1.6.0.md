# OpenAula v1.6.0

Dynamic Wave 9-Direction, Trigger Response Cross Waves, 16 Log-Spaced Rhythm Equalizer & Smooth Multi-Color Wraparound.

## Dynamic Wave Effect (`wave`)

- Multi-directional color waves across all 9 directions (`top-left`, `top`, `top-right`, `left`, `center`, `right`, `bottom-left`, `bottom`, `bottom-right`) plus legacy horizontal/vertical directions.
- True radial outward expansion (`center`) originating from the keyboard center.
- Continuous circular palette interpolation across stops, eliminating angular jumps, 30-degree quantization snaps, and seam color pop.
- Usable as a Base Effect or composable Layer Effect with intuitive direction grid controls, wave width, speed, and palette selectors.

## Trigger Response Effect (`trigger`)

- Interactive cross-shaped wave along both row and column triggered on key press.
- Cyclic progression through 5-color palette stops (`trigger`) on each subsequent key press.
- Physical key hold keeps origin lit until released.
- Additive color blending (`addPixel`) where overlapping cross arms combine harmoniously.

## Rhythm Sync 16 Log-Spaced Equalizer & Expanded Modes

- Replaced linear frequency distribution with 16 log-spaced equalizer bands across 64 FFT bins (~187.5 Hz to ~11.8 kHz). Spreads vocal and melodic energy evenly across all 68 keys.
- **3 New Key Modes:**
  - **Mode 429:** Spectrum Bars (Cột phổ)
  - **Mode 432:** Audio Marquee (Chữ chạy âm thanh)
  - **Mode 434:** Radial Chase (Đuổi hình tròn)
- **3 New Side Meter Modes:**
  - **Mode 504:** Loop 18 slots
  - **Mode 505:** Peak-hold meter (holds transient peak level, decays smoothly)
  - **Mode 506:** Far-end meter (mirrored side display)
- Comprehensive architecture documentation added to `docs/RHYTHM_SYNC_OPENRGB.md`.

## WIN 68 HE MAX Preview & Hardware Stability

- Smooth phase wrapping for ported internal modes `201..212` in `AulaWin68ExactRgbEngine`.
- Latched `pendingPress` buffer ensures rapid taps are never skipped between render frames.
- Guarded WebHID writes when Custom RGB or Rhythm live streaming is running to prevent packet collisions.
- Preserved color group priority during frame palette merging in `service/frame.ts`.
