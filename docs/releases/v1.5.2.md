# OpenAula v1.5.2

Custom Effects Multicolor Restoration, Dedicated Gaming Preset Color Separation & Hardware Save Fixes.

## Multicolor & Single Color Controls in Custom Effects

- Restored the Multicolor option and unified 8-color swatch grid (including Slot 0 Multicolor with rainbow indicator) for non-gradient effects (Ripple, Reaction, Breath, Scan, Trail, Touch, Pressure Wave, Jelly, AOE).
- Automatically hide the redundant Single Color picker and controls for gradient effects (Aurora, Comet, Ember, Starlight, Afterglow, Pulse), directly exposing gradient palettes (`RGB_GRADIENT_PALETTES`).
- Layer Stack sidebar displays rainbow dots (`is-rainbow`) for layers with multicolor enabled.

## Dedicated Gaming Preset Color Separation & Templates

- Introduced independent `presetColors` caching across both Custom Effects and Onboard Effects for all per-key modes (Mode 22 WASD, Mode 23 MOBA, Mode 24 RTS, Mode 25 MMO, Mode 26 User Custom):
  - Changing colors in User Custom Preset no longer overwrites or mirrors into MOBA, WASD, or other presets.
  - Switching back to any preset cleanly restores its previously customized colors.
- Built-in recommended default lighting templates for gaming presets:
  - **Mode 22 (WASD / FPS):** Cyan movement keys (WASD), Yellow arrow keys, Orange modifiers, Green reload (R), Gold weapons (1-3).
  - **Mode 23 (MOBA):** Cyan/Crimson abilities (QWER), Amber summoner spells (DF), Lime active items (1-6), Yellow ward (7), Purple recall (B).
  - **Mode 24 (RTS):** Blue control groups (1-5), Orange grid commands (QWER/ASDF/ZXCV), Yellow global commands (H/M/P), Mint modifiers.
  - **Mode 25 (MMO):** Red-Orange action bars (1-0/=), Cyan movement (WASD/QE), Purple targets/modifiers, Yellow UI panels (I/M/C).
  - All non-gaming keys default to off (`[0, 0, 0]`).

## Hardware Save & Profile Synchronization

- Fixed Custom Effects base mode selection not updating `value.keys.mode`, allowing gaming presets to properly trigger hardware mode writes (`0x18` on WIN 68 HE MAX and packet 4 on HERO 68) when clicking "Save to profile".
- Fixed `customRgbPending` check in `App.tsx` and `useDeviceSyncController.ts` which previously prevented HERO 68 users from saving Custom Effects to hardware.
- Real-time WebHID per-key LED updates when painting keys in Custom Effects on WIN 68 HE MAX.
