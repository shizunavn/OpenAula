# OpenAula v1.3.3.0

WIN 68 HE MAX Disassembly-Verified Protocol: Global Actuation, Switch Calibration Curves & SRAM Flash Guard.

## Global Actuation (`0x29` / `0xA9`)

Support for WIN 68 HE MAX global actuation setting via opcode `0x29`:
- Reads and writes global actuation points in micrometres (100..3400 µm).
- Automatically updates all non-overridden keys (`Header & 0x30 == 0`) matching official driver behavior.

## Verified Per-Key Feature Table (`0x23`)

All per-key field offsets pinned against firmware disassembly tables (`VA 0x1C6DC` and `VA 0x1C744`):
- `0x04`: Travel depth in micrometres.
- `0x08`: Key mode header (bit 5 `0x20` for Rapid Trigger enable, bits 0..3 for advanced key types).
- `0x14`: Rapid Trigger Press sensitivity in µm.
- `0x15`: Rapid Trigger Release sensitivity in µm.
- `0x16`: Top Deadzone in µm.
- `0x17`: Bottom Deadzone in µm.
- `0x19`: Magnetic switch curve ID (0=Wing Chun, 1=Jade Pro, 2=Black King, 3=Meteor Magnetic).

## Travel Sanitization & Switch Calibration

- Automatic sanitization based on switch curve: 3400 µm maximum travel for Curve 0 (Wing Chun / Jade Pro) and 3300 µm for Curve 1 (Black King / Meteor Magnetic).
- Full integration with Switch Selector UI and asset visualizers.

## Flash Flush Guard for Profile Switching

- Guarded `0x00 0x70` profile slot switching against the firmware's 500 ms deferred Flash write timer (`VA 0x07E28` -> `0x11914` vs `VA 0x16342` -> `0x12AF4`).
- Synthetic immediate reply when re-selecting the current active profile with pending SRAM writes, preventing uncommitted settings from being overwritten with stale Flash.
