# OpenAula v1.4.0

WIN 68 HE MAX Rhythm Sync Native Service & WebHID Direct Streaming.

## Direct WebHID Rhythm Sync

Rhythm Sync can now run on WIN 68 HE MAX directly from the browser without requiring OpenAulaService:
- Web Audio API analyzes microphone or desktop audio directly in the web tab.
- `XsydCustomRgbStreamer` drives animations to the hardware:
  - Adaptive transmission: compact single-key writes (`LEN = 0x05`) when `<= 4` keys change.
  - High-throughput 14-slot batch writes (`LEN = 0x39`) sending at most 5 USB packets for all 68 keys when whole-board effects animate.
- Graceful handover between WebHID direct streaming and background service execution.

## Native Service Optimization

- `service/native/rhythm_core.h`:
  - Updated color palette in `xsydPerKeyModeReport` matching official `rhythm_capture.pcapng` capture (#0014).
  - Unused batch slots padded with `0x00 0x00 0x00 0x00` per wire specification (#0021, #0030, #0040).
  - Streamlined encoding loops and zero frame drops on active music playback.

## Audio Engine Enhancements

- Improved frequency bandpass filtering and dynamic sensitivity thresholds.
- Synchronized lighting across both HERO68/84 and WIN 68 HE MAX hardware.

## Validation

677 JavaScript tests pass, the web application builds with Vite, and both TypeScript projects (UI and service) typecheck cleanly.
