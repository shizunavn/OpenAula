# OpenAula v1.7.1

Native System Tray Flyout, Service Control Panel Dashboard, and HERO 68 XS 5 µm Precision Synchronization.

## Native System Tray & Windows Background Service

- **Native Dark-Themed System Tray Flyout**:
  - Implemented a custom Win32 GDI-rendered tray flyout in `service/native/launcher.cpp` featuring real-time diagnostic status cards: ViGEm driver presence, active WebHID bridge, device profile slot, and RT/AP mode status.
  - Added direct quick-action buttons: Open Web Application, Service Control Panel, Restart Service, and Exit.
  - Linked `gdi32.lib` in `service/build.mjs` and native launcher build script.
- **Responsive Local Service Control Panel (`service/controlPanel.ts`)**:
  - Revamped the diagnostic interface on `http://127.0.0.1:16868/` with modern dark styling, responsive metrics cards, real-time polling telemetry, and immediate profile switching.
- **HERO 68 XS Wire Travel Normalization**:
  - Implemented travel scaling (`/ 2` and `/ 200`) in `service/native/hid_bridge.cpp`, `service/gamepadDigital.ts`, and `service/rgb/rgbController.ts` so high-resolution `0.005 mm` wire precision maps consistently to standard `0.01 mm` analog gamepad and RGB pressure calculations.

## HERO 68 XS Precision & Performance Slider Synchronization

- **High-Precision Actuation & Rapid Trigger Display**:
  - Resolved millimeter rounding inconsistencies between sliders and keyboard preview overlays by migrating to `formatMillimeters()`, natively displaying `0.005 mm` and `0.025 mm` steps.
  - Added automatic promotion to discrete 5 µm tables (`RAPID_TRIGGER_VALUES_XS`) in `RangeControl.tsx` and `VerticalRangeControl.tsx` when values or step sizes reflect 5 µm resolution.
- **UI & Badge Styling Refinements**:
  - Widened meter input controls from 34px to 48–52px across `QuickSettingsPage`, `RapidPage`, `ActuationPage`, and custom controls to accommodate 3-decimal millimeter strings without clipping.
  - Scaled keycap value badge font sizing (`0.92em`) to cleanly display 3-decimal values (`0.005`, `0.025`) directly on the preview stage.
- **Device Model Auto-Detection**:
  - Harmonized HERO 68 XS identification across WebHID (`src/protocol/hero68/webhid.ts`) via Zone 6 RT precision probing and through the Windows background service transport.

## Verification & Test Suite

- Maintained 100% test pass rate across all 693 integration, protocol, and unit tests.
- Formatted and validated through Prettier, ESLint, TypeScript service compiler, and Vite client production build.
