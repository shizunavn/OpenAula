# OpenAula v1.8.0

Wootility v5 Visual Icon Picker, Auto-Profile Switcher, 4 Onboard Slots, and XSYD Smart Slot 3 Virtualization.

## Auto-Profile Switching & Zero Flash Wear Execution

- **Background Auto-Profile Engine**:
  - Implemented high-performance foreground process monitor leveraging Win32 native APIs (`QueryFullProcessImageNameW`, `EnumWindows`) with an asynchronous 500 ms sampling rate and an 800 ms debounce window to avoid switching during rapid Alt-Tab operations.
  - Linked applications rule engine supporting executable name matching (with fnmatch wildcard support: `cs2.exe`, `*valorant*.exe`), installation directory matching, window title pattern matching, and full executable path detection.
  - Hardware executor enforcing zero Flash wear:
    - **HERO68 / HERO84**: Uses fast onboard slot switching (`CMD 0x10`) or diff-based volatile RAM streaming (`0x15 -> 0x13 -> 0x19 -> 0x16`), strictly blocking destructive Flash write commands (`0x03`, `0x05`, `0x06`).
    - **WIN 68 HE MAX (XSYD 0x5C)**: Uses slot switching (`0x00 0x70`) combined with volatile SRAM lighting updates (`0x2A`), strictly filtering out persistent Flash write commands (`0x23`, `0x29`).

## XSYD Smart Slot 3 Virtualization

- **Smart Dynamic Scratchpad (Slot 3)**:
  - Slots 0, 1, and 2 operate as static onboard hardware profiles with 0 Flash wear.
  - Slot 3 acts as a high-speed dynamic scratchpad for linked profiles #4 through #100+:
    - **Alt-Tab Session Cache Hit**: Switching back and forth to an active game session reuses Slot 3 with 0 Flash wear.
    - **Warm-Up Dwell & Token-Bucket Wear Guard**: New game sessions undergo a 12-second dwell buffer before persistence, protected by a hardware token-bucket rate limiter (maximum 10 commits per hour) to safeguard SPI Flash endurance.

## Wootility v5 Visual Icon Picker & 4 Onboard Slots

- **Visual Profile Customization**:
  - Full suite of 89 Wootility profile icons categorized into `SWITCHY & UwU`, `WOOTING`, and `GRADIENTS`.
  - 6 preset image banners: FPS, Racing, Typing, Analog Movement, TenZ Pro FPS, and Custom.
  - Introduced **TenZ Pro FPS Preset** tuned with 0.1 mm actuation and 0.15 mm Rapid Trigger.
  - Automatic dominant color extraction from linked application names.
- **4 Onboard Slots Architecture**:
  - Extended hardware slot capabilities to 4 slots (`0 | 1 | 2 | 3`) tailored for WIN 68 HE MAX and multi-slot devices.
