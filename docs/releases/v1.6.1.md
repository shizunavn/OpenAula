# OpenAula v1.6.1

Rhythm Sync Speed Control, Side Light Hardware Isolation & Row-Normalized Equalizer Columns.

## Rhythm Sync Speed Control & Position-Driven Modes

- Added configurable `speed` parameter (ms per full sweep, valid range 250..4000 ms, default 1300 ms) for:
  - **Mode 432:** Audio Marquee (Chữ chạy âm thanh)
  - **Mode 434:** Radial Chase (Đuổi hình tròn)
- Upgraded `RhythmConfiguration` schema to `version: 2` with automatic, lossless migration of existing `version: 1` drafts via `restoreRhythm()`.
- Extended the native background bridge IPC command to **15** positional fields (`rhythm:<keyMode>;<sideMode>;<brightness>;<sensitivity>;<releaseMs>;<speed>;...`).
- Synchronized Web Audio and native C++ timestamp units in ms, ensuring the sweep cycle precisely matches the configured `speed` (1300 ms = exactly one cycle).
- Bypassed envelope release smoothing (`fixedRelease`) for position-driven modes 432 and 434, eliminating trailing ghosting artifacts.
- Automatically hidden the release / smoothing slider in the UI for modes where release smoothing does not apply (Modes 169, 432, 434).

## Row-Normalized Equalizer Column Geometry

- Introduced `Key::nx` (row-relative horizontal position `0..1`) into `service/native/rhythm_core.h` geometry calculations.
- Normalized column mapping for **Mode 429 (Spectrum Bars)** and **Mode 432 (Audio Marquee)** across variable-width key rows (such as the number row and spacebar row), eliminating gaps and ensuring all 16 frequency bands span each row evenly.

## Side Light Hardware Isolation

- Saving side light edits from tabs other than `onboard` no longer calls `rgbService.mode('onboard')`, preventing active host playback (Custom Effects or Rhythm Sync) from being interrupted.
- Added explanatory notes across Custom RGB and RGB Settings pages to inform users that Side Light settings are stored directly on the physical keyboard while key effects run live via the background service.

## Localization & Verification

- Added Vietnamese translation strings for `Scroll speed`, `Time for one full sweep. Higher is slower.`, and side light persistence notes.
- Updated technical architecture reference in `docs/RHYTHM_SYNC_OPENRGB.md`.
- Expanded test suite:
  - `tests/native-rhythm.test.cpp`: validates 15-field parser, Marquee cycle exactness at 1300 ms, and Spectrum Bars column rendering.
  - `tests/rhythm.test.mjs`: validates `version: 2` schema, bounds checking (speed 250..4000), v1 -> v2 migration, and 15-field native command serialization.
